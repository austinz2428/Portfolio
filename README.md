# Austin Zilincik — Portfolio

A minimalist personal website and portfolio built with React, Vite, and Tailwind CSS, featuring an etched Apollo 11 Saturn V launch backdrop.

**Live site:** [https://austinz2428.github.io/Portfolio/](https://austinz2428.github.io/Portfolio/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
